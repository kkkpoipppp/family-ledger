# 家庭工账（Family Ledger）

一款面向家庭服装加工生意的 Android 计件工资账本。它把纸质账本里的“谁做了什么、做了多少件、每件多少钱、预支了多少、什么时候结清”整理成简单的手机流水，并支持离线使用和多手机共同记账。

当前版本：`v0.4.0`

## 为什么做这个项目

家庭服装加工的工资通常不是日结，而是持续记录几个月后统一结算。传统手写账本不方便查询、汇总和核对，也容易在两个人同时记账时产生遗漏。本项目围绕这种实际工作方式设计：平时只记做工与预支，半年或需要发薪时再自由选择日期区间结算。

## 主要功能

- 工人管理：在职、离职、恢复在职及历史账本保留。
- 计件记账：衣服、裤子、长款、短款和自定义工序。
- 自动计算：数量 × 单价，流水保存当时的单价与项目快照。
- 工资预支：单独记录预支金额、日期和备注。
- 区间结算：自由选择任意开始日期和结束日期，不限制日结或固定周期。
- 结算核对：按款式、长短、工序汇总件数和金额。
- 结算历史：保留付款记录，支持通过冲正流水撤销错误结算。
- 永久删除：输入工人姓名二次确认后，清除本地和云端的相关资料。
- 离线优先：未配置云服务时，可作为完全本机版使用。
- 多设备同步：使用同一 CloudBase 地址和家庭同步码的设备可以共同编辑，不限定只能两部手机。
- 自动补同步：网络恢复后由 WorkManager 按退避策略重新同步。
- JSON 备份：支持本地导出与恢复，兼容旧版本备份。

## 数据可靠性

- Room 事务保证结算、撤销、永久删除和备份快照的一致性。
- 保存按钮锁和操作编号共同防止重复点击造成重复入账。
- 开启共同编辑后，结算与撤销由云端事务执行，避免多台手机重复结工资。
- 云端写入前校验金额、流水类型、修订号和跨表引用。
- 永久删除会保留一个不含姓名和账务内容的删除标记，防止离线旧设备重新上传已删除工人。
- 新同步配置只有测试成功后才会保存，失败时继续保留原配置。

## 技术结构

| 部分 | 技术 |
|---|---|
| Android 客户端 | Kotlin、Jetpack Compose、Room、WorkManager |
| 本地数据 | SQLite / Room，schema version 3 |
| 云同步 | 腾讯云 CloudBase HTTP 云函数、文档型数据库 |
| 云函数 | Node.js 20 |
| 构建 | Gradle 9.3.1、Android SDK 36、JDK 17+ |

## 构建 Android 客户端

准备 JDK 17+、Android SDK 36 后运行：

```powershell
.\gradlew.bat testDebugUnitTest :app:assembleDebug
```

调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

正式发布前请按照 [`docs/RELEASE_SIGNING.md`](docs/RELEASE_SIGNING.md) 创建并妥善备份自己的签名密钥，然后运行：

```powershell
.\build-release-apk.cmd
```

签名密钥、密码配置、APK 成品、Android SDK、Gradle 缓存和本机路径配置均被 `.gitignore` 排除，不应提交到仓库。

## 部署共同编辑服务

云函数源码位于 [`cloudbase/ledger-sync`](cloudbase/ledger-sync)。请参考云服务商的官方文档，把它部署到你自己的 Node.js 云函数环境中。

部署时需要自行生成家庭同步码，并只在自己的云端控制台中配置对应摘要。公开仓库不提供具体账户凭证、网关路由或云端运维参数，也不包含真实同步码、云环境地址、数据库内容或发布密钥。

## 隐私与安全提醒

- 本项目不会读取或上传通讯录、照片等无关资料。
- 开启云同步后，账本副本会保存在你自己的 CloudBase 环境中。
- 不要把家庭同步码、同步码哈希、真实云函数地址、签名密钥或 `keystore.properties` 提交到公开仓库。
- “永久删除”不可撤销，但以前单独导出的 JSON 文件不会被自动清理，需要用户自行保管或删除。
- 正式用于工资结算前，请先完成备份和双设备同步验收。

## 项目定位

这是为小规模家庭服装加工场景制作的实用工具，不是通用财务、税务或劳动工资系统。金额与结算结果仍应由使用者核对，并保留必要的线下凭证。

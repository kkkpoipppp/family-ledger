# 家庭工账安装与使用

## 安装到安卓手机

1. 把签名正式版 `family-ledger-cloud-v0.4.0-release.apk` 发送到手机，或用数据线复制到“下载”文件夹。文件名带 `debug` 的版本只用于开发验收。
2. 在手机上点开 APK。若系统提示“不允许安装未知应用”，只为当前使用的文件管理器临时允许安装。
3. 安装完成后，建议把“允许安装未知应用”重新关闭。
4. 打开“家庭工账”，先添加工人，再记录做工或预支。

同一发布密钥签名的正式版升级时不要卸载旧版；直接覆盖安装才能保留手机里的账本。只有第一次从 `debug` 验收版切换到正式版时，因为签名不同，才需要先确认云同步并导出 JSON，再卸载旧版后安装正式版。无论是否升级，都建议先导出一次 JSON 备份。

## 怎样使用

- 平时：每完成一批衣服或裤子，就记数量、单价和日期。
- 给工人预支工资时：记一笔预支。
- 半年或需要结工资时：进入“工资结算”，自由选择开始日期和结束日期，核对后确认结清。
- 结算前：核对长裤、短裤、上衣等件数汇总和应付金额。
- 结算选错时：从“结算历史”选择撤销，填写原因。应用会保留原付款并增加等额冲正流水。
- 换手机或结算后：导出备份文件，并把文件另外保存一份。
- 工人离职时：在“工人”页面点“设为离职”。应用会先显示是否还有应付余额；即使强制离职，历史流水也不会删除。
- 确实需要彻底清除某人时：点“永久删除”，阅读警告并输入该工人的姓名。此操作会删除本机和云端的全部相关资料，无法撤销；以前导出的旧备份文件需要自行清理。
- 不再使用某个做工项目时：在“记一笔工钱”的“管理/停用项目”中停用；旧账仍保留。

## 两部手机共同编辑

按 [`CLOUDBASE_DEPLOY.md`](CLOUDBASE_DEPLOY.md) 配置同一个同步地址和家庭同步码后，两部手机会合并账本。第一次开启时先配置原来有完整数据的主手机，确认同步成功后再配置第二部。普通记账允许离线；网络恢复后，后台任务会自动补同步并按退避策略重试。工资结算和撤销在开启共同编辑后需要联网。

## 数据与隐私

未开启云同步时账本只保存在手机本地；开启后，账本副本会通过 HTTPS 保存到你的 CloudBase 环境。应用不会上传通讯录、照片等无关数据。卸载应用会清除本机数据库，所以卸载前仍应先导出备份。
